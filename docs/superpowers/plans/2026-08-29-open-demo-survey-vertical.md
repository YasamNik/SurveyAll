# Open-Demo Survey Vertical Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A publicly reachable SurveyAll demo — create, publish, answer, and view results for surveys — served from this machine through a Cloudflare quick tunnel, with **auth deferred: the app is fully open**.

**Architecture:** Next.js App Router over a pure-TS domain layer (`lib/domain`), Drizzle/Postgres underneath, per the 2026-08-29 design. Auth deliverable is deferred (owner decision 2026-08-29): no sign-in, `author_id` stays NULL, authoring UI is open to anyone with the URL. Scheduling domain is a later plan.

**Tech Stack:** Next.js 15 (App Router), TypeScript strict, Tailwind, pnpm (via corepack), Drizzle ORM + drizzle-kit, pg, Zod, Vitest, Postgres 17 in Docker, cloudflared (Docker image, quick tunnel).

**Spec:** `docs/superpowers/specs/2026-08-29-surveyall-design.md` (product/§3/§4 carried from `2026-08-27-surveyall-design.md`).

## Global Constraints

- `lib/domain/**` imports nothing from `next/*`, `react`, `drizzle-orm`, `next-auth`, `@auth/*` — ESLint-enforced from Task 1.
- TypeScript `strict: true`; `pnpm typecheck && pnpm lint && pnpm build` must stay green at every commit.
- `DATABASE_URL` is the only way the app knows the DB. Dev value: `postgres://surveyall:surveyall@localhost:5433/surveyall` (port **5433** to avoid clashing with any local Postgres).
- All migrations generated by `drizzle-kit generate`, committed under `drizzle/`.
- Public API paths exactly as in spec §4 (`/api/v1/...`). Public survey endpoint must never return results.
- Every new env var also goes into `.env.example`.
- pnpm is invoked as `corepack pnpm` unless `corepack enable` has been run (do that in Task 1).
- Commit after every task (green checks first). Push to `origin main` after Tasks 4, 8, 11.

**Interfaces:**

- [ ] **Step 1: Extend schema** — append to `lib/db/schema.ts`:

```ts
import { pgTable, text, timestamp, boolean, integer, doublePrecision, jsonb, uniqueIndex } from 'drizzle-orm/pg-core';
import { sql } from 'drizzle-orm';

export const surveys = pgTable('surveys', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  authorId: text('author_id').references(() => users.id),
  title: text('title').notNull(),
  description: text('description'),
  status: text('status', { enum: ['draft', 'published', 'closed'] }).notNull().default('draft'),
  slug: text('slug').unique(),
  showResultsToRespondents: boolean('show_results_to_respondents').notNull().default(false),
  publishedAt: timestamp('published_at', { withTimezone: true }),
  closedAt: timestamp('closed_at', { withTimezone: true }),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
});

export const questions = pgTable('questions', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  surveyId: text('survey_id').notNull().references(() => surveys.id, { onDelete: 'cascade' }),
  position: integer('position').notNull(),
  prompt: text('prompt').notNull(),
  required: boolean('required').notNull().default(false),
  type: text('type', { enum: ['single_choice', 'multi_choice', 'free_text', 'rating'] }).notNull(),
  config: jsonb('config'),
});

export const questionOptions = pgTable('question_options', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  questionId: text('question_id').notNull().references(() => questions.id, { onDelete: 'cascade' }),
  position: integer('position').notNull(),
  label: text('label').notNull(),
});

export const surveyResponses = pgTable('survey_responses', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  surveyId: text('survey_id').notNull().references(() => surveys.id, { onDelete: 'cascade' }),
  userId: text('user_id').references(() => users.id),
  submittedAt: timestamp('submitted_at', { withTimezone: true }).defaultNow().notNull(),
  clientToken: text('client_token'),
  ipHash: text('ip_hash'),
}, (t) => [
  uniqueIndex('one_response_per_user').on(t.surveyId, t.userId).where(sql`user_id is not null`),
]);

export const answers = pgTable('answers', {
  id: text('id').primaryKey().$defaultFn(() => crypto.randomUUID()),
  responseId: text('response_id').notNull().references(() => surveyResponses.id, { onDelete: 'cascade' }),
  questionId: text('question_id').notNull().references(() => questions.id, { onDelete: 'cascade' }),
  optionId: text('option_id').references(() => questionOptions.id),
  textValue: text('text_value'),
  numberValue: doublePrecision('number_value'),
}, (t) => [
  uniqueIndex('one_answer_cell').on(t.responseId, t.questionId, t.optionId).nullsNotDistinct(),
]);
```

(The nulls-not-distinct unique index replaces the spec's impossible nullable-PK; reasoning stays the same — one row per response/question/option cell.)

```ts
// errors.ts
export type DomainErrorCode = 'NOT_FOUND'|'SURVEY_CLOSED'|'NOT_PUBLISHED'|'QUESTIONS_FROZEN'|'INVALID_ANSWER'|'RESULTS_HIDDEN';
export class DomainError extends Error { constructor(public code: DomainErrorCode, message?: string) }

// slug.ts
export function randomSlug(len?: number): string  // default 8, [a-z0-9]

// types.ts
export type QuestionType = 'single_choice'|'multi_choice'|'free_text'|'rating';
export type SurveyStatus = 'draft'|'published'|'closed';
export interface RatingConfig { min: number; max: number }
export interface OptionInput { id?: string; label: string }
export interface StoredOption { id: string; position: number; label: string }
export interface QuestionInput { prompt: string; type: QuestionType; required: boolean; config?: RatingConfig | null; options: OptionInput[] }
export interface QuestionWithOptions { id: string; position: number; prompt: string; required: boolean; type: QuestionType; config: RatingConfig | null; options: StoredOption[] }

// reconcile.ts
export interface OptionPlan { inserts: { label: string; position: number }[]; updates: { id: string; label: string; position: number }[]; deletes: string[] }
export function reconcileOptions(stored: StoredOption[], incoming: OptionInput[], status: SurveyStatus): OptionPlan
// throws QUESTIONS_FROZEN if status !== 'draft' and the plan contains inserts or deletes (renames/reorders of existing ids allowed only in draft; when published, ONLY label changes allowed — position changes also frozen)

// respond.ts
export type AnswerValue = string | string[] | number;  // option id(s) or text or rating
export interface AnswerRow { questionId: string; optionId: string | null; textValue: string | null; numberValue: number | null }
export function validateResponse(questions: QuestionWithOptions[], input: Record<string, AnswerValue | undefined>): AnswerRow[]
// throws INVALID_ANSWER on: missing required answer, unknown question id in input, option id not in question, multi answers to single_choice, rating out of config range, empty free text on required

// tally.ts
export interface QuestionResult { questionId: string; prompt: string; type: QuestionType; optionCounts?: { optionId: string; label: string; count: number }[]; texts?: string[]; ratingAverage?: number | null; ratingCounts?: { value: number; count: number }[] }
export function computeTally(questions: QuestionWithOptions[], answers: AnswerRow[]): QuestionResult[]
// optionCounts includes zero-count options, ordered by option position
```
